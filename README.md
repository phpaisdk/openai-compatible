# PHP AI SDK — OpenAI-Compatible Adapters

Shared request, response, and streaming adapters for building OpenAI-compatible providers with the [PHP AI SDK](https://phpaisdk.com). Covers Chat Completions, Responses, images, audio, and embeddings.

## Installation

```bash
composer require aisdk/openai-compatible
```

This is a provider development package. For application usage, install a provider such as [`aisdk/openai`](https://github.com/phpaisdk/openai), [`aisdk/groq`](https://github.com/phpaisdk/groq), or [`aisdk/openrouter`](https://github.com/phpaisdk/openrouter).
